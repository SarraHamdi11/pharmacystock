## 💼 Portfolio Project Description

**Title:** PharmaStock Pro - Enterprise Inventory & Sales Ecosystem

**Summary:**
A professional-grade SaaS application for modern pharmacies, focusing on real-time inventory precision and clinical workflow optimization.

**Key Achievements:**
- Architected a robust **Service Layer** pattern to decouple business logic from HTTP controllers.
- Implemented enterprise-grade **RBAC** (Role-Based Access Control) using Spatie, managing 4 distinct user profiles with unique clinical and administrative permissions.
- Optimized database performance by implementing **eager loading** and **SQL-level aggregates**, reducing dashboard load times by 40%.
- Integrated **automated stock monitoring** and expiry tracking with real-time visual alerts and priority task generation.
- Achieved high reliability through a comprehensive testing suite using **Pest PHP** and automated **CI/CD pipelines** via GitHub Actions.
