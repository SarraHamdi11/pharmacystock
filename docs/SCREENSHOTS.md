# 📸 Screenshot Plan - PharmaStock Pro

To make your portfolio stand out, capture these specific views. Place the resulting `.png` files in the `public/screenshots/` directory.

### 1. `login.png`
- **View**: The login page.
- **What to show**: The clean "card-glass" design, the demo profile selector, and the "PharmaStock" branding.
- **Tip**: Click a profile so the email is filled before taking the shot.

### 2. `dashboard.png`
- **View**: The main dashboard after logging in as Admin.
- **What to show**: The KPI cards (Revenue, Orders, etc.), the Sales Analytics chart, and the Priority Tasks sidebar.
- **Tip**: Ensure there is some seed data so the charts aren't empty.

### 3. `products.png`
- **View**: The Products Index page.
- **What to show**: The grid/table of medications, category badges, and the search/filter bar.
- **Tip**: Show a mix of stock levels (green for healthy, red for low).

### 4. `orders.png`
- **View**: The Create Order page (POS).
- **What to show**: The dynamic item selection and the real-time total calculation.

### 5. `reports.png`
- **View**: Any report page (e.g., Inventory Report).
- **What to show**: The detailed data table and the export buttons (Excel/PDF).

### 6. `audit-log.png`
- **View**: The Activities page.
- **What to show**: The sequence of system actions (e.g., "Admin updated medication", "Pharmacist created order").
- **Tip**: This proves your "Audit Trail" feature works.

### 7. `mobile-view.png`
- **View**: Dashboard on a mobile breakpoint.
- **What to show**: The responsive sidebar (collapsed) and stacked KPI cards.
- **Tip**: Use Chrome DevTools (Cmd+Shift+M) to simulate a mobile device.
