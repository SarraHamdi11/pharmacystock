# 🚀 15-Minute FREE Hosting - Quick Start

## 🎯 FASTEST WAY TO HOST YOUR PHARMACY SYSTEM

### **Step 1: Database (5 minutes)**
1. Go to **https://railway.app**
2. Click **"New Project"**
3. Select **"MySQL"**
4. Wait 2 minutes
5. Click **"MySQL"** → **"Connect"**
6. **Copy** the connection string

### **Step 2: Deploy App (10 minutes)**
1. Go to **https://vercel.com**
2. Click **"New Project"**
3. **Import** your GitHub repository
4. **Add Environment Variables:**
   ```
   APP_KEY=base64:YOUR_KEY_HERE
   DB_CONNECTION=mysql
   DB_HOST=your-railway-host.railway.app
   DB_PORT=3306
   DB_DATABASE=railway
   DB_USERNAME=railway
   DB_PASSWORD=YOUR_RAILWAY_PASSWORD
   APP_URL=https://your-app-name.vercel.app
   ```
5. Click **"Deploy"**

### **Step 3: Done! 🎉**
Your pharmacy system is now live at: `https://your-app-name.vercel.app`

### **If you see errors:**

4. **Charts not working**: Check JavaScript console
